# Process Reflection

## What I Built

I built two new features for my professional photography service website:

- **Gallery Page** — a page where users can share photos taken by the service, browsable alongside the studio's own portfolio
- **Reviews Page** — a page where users can submit reviews about their experience with the studio

---

## Thoughts on Micro-Iteration

Micro-iteration feels very roundabout to me. Working in small steps and understanding how everything works can be helpful, but it impedes workflow and efficiency. I think the same results — and the same level of understanding — can be achieved faster by working as efficiently as possible from the start.

---

## Self-Review

Self-review caught 5 bugs in the code that I hadn't noticed before. One example was on the contact page: whenever you submitted the form, the page reloaded with no feedback to the user. The review also surfaced a lot of missing error handling throughout the codebase that would have caused silent failures.

---

## Claude Web vs. Claude Code

Claude Web is useful. It felt pretty similar to using Claude Code in PowerShell — the experience and capabilities were comparable across both interfaces.

---

## When Micro-Iteration + Self-Review Makes Sense

The scenario where I would combine micro-iteration with self-review is when I want to add a feature or function that I am unsure about — specifically when I don't fully understand how it works yet. In those cases, the slower, step-by-step approach helps build understanding before scaling up the pace.
